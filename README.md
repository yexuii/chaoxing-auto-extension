# 超星学习通自动倍速与任务点助手 (Chaoxing Auto Speed & Task Helper)

一款面向 **Chrome / Edge (Manifest V3)** 的超星学习通（泛雅 MOOC）章节学习辅助浏览器扩展，支持 **[1, 16] 自由倍速调节**、按服务端实测倍速上限控速的 **MAX 档位**、**视频 / PPT / PDF 全任务点自动完成**、**自动切换下一节** 以及 **可拖动悬浮窗 + 工具栏弹窗双控**。

---

## 功能特性

- **[1, 16] 无级调速与快捷预设**：
  - 支持滑块微调（步长 `0.05x`）、数字输入框精确输入，以及 `1x` / `2x` / `3x` / `4x` / `8x` / `16x` 快捷按钮。
  - 自动解除超星 `videojs-ext` 倍速限制、进度条拖动限制与窗口失焦暂停检测。
- **MAX 档位（按服务端要求的真实观看时长控速 + 通过后 16x 冲刺）**：
  - **实测的服务端规则**（`rt=0.9`、课程允许倍速 `ds_1`）：播放器每约 `60.4s` 上报一次心跳（`isdrag=0`）。服务端累计同一任务点各次心跳之间的真实时间（跨会话、重播都累计），达到约 `视频时长 × rt ÷ 2`（即约 **45%**，相当于平均最高 2 倍速）后，下一次心跳返回 `isPassed:true`。
    - 3148s 视频：真实时长 37% 时仍未通过，约 45% 时通过。
    - 3106s 视频：真实时长 43.2% 时仍未通过，下一次心跳（约 45%）通过。
    - 判定与心跳倍速无关：2.5x、3x、3.6x 发出的心跳都同样计时；只按 3x 跑完整个视频（约 33%）会在结束时返回 `isPassed:false`。
  - **控速策略**：所需时长 $T = \lceil D \cdot rt / 2 \rceil + 75\text{s}$（多留一次心跳的余量），倍速 $R = \operatorname{clamp}\left(\frac{D - \text{当前进度}}{T - \text{已看时长}},\, 1,\, 3\right)$，通常约 `2.2x`，让视频正好在时长达标时播完。服务端返回 `{"isPassed": true}`（或 DOM 出现 `ans-job-finished`）后自动 **16x 冲刺**并进入下一节；非任务点视频直接 16x。
  - 已看时长只统计进度实际在走的时间，卡顿/缓冲不计入。
  - 播放时自动保持 `1%` 微音量，防止 Chromium 在后台标签页暂停静音视频。
- **视频线路卡死自动恢复**：
  - 播放中若进度连续 8 秒不动（常见于某条 CDN 线路请求挂起），自动切换到另一条"公网"线路继续播放。
  - 切换线路时播放器会短暂把进度读成 0 并上报 `playingTime=0` 的心跳，服务端会据此把之前累计的进度作废。扩展会拦截这一条错误心跳，保住已有进度。
  - 视频播完但任务点仍未通过时，自动从头重播（已覆盖的进度服务端仍保留，通常一次合规心跳即可通过）。
  - 新章节视频（`preload="none"`）会被自动触发加载，不会停在"视频加载中"。
- **开关键位与快捷键 (`Alt + S`)**：
  - 点击悬浮窗右上角开关按钮、扩展工具栏弹窗开关，或按下快捷键 `Alt + S` 即可随时开启/关闭。
  - 关闭时自动将当前视频恢复为 `1x` 正常倍速并停止自动跳转。
- **全类型任务点识别与自动下一节**：
  - 自动识别并完成视频、PPT、PDF 文档任务点（等待服务端返回 `isPassed: true` / `ans-job-finished` 后再跳转，杜绝漏刷与橙色未完成标记）。
  - 当前章节所有卡片完成后自动进入下一章节，到达末尾时自动回扫未完成章节。
- **可拖动悬浮窗与状态持久化**：
  - 按住悬浮窗标题栏即可自由拖动，窗口坐标、倍速档位、开关状态自动保存在 `localStorage`。

## 安装方法（Chrome / Edge）

1. 下载本仓库源码（或解压 `chaoxing-extension.zip`）。
2. 打开浏览器扩展管理页并开启**开发者模式**：
   - **Microsoft Edge**：地址栏输入 `edge://extensions/` 并回车，开启左侧或右上角的 **“开发人员模式” (Developer mode)**。
   - **Google Chrome**：地址栏输入 `chrome://extensions/` 并回车，开启右上角的 **“开发者模式” (Developer mode)**。
3. 点击 **“加载解压缩的扩展” (Load unpacked)**，选择本项目的文件夹（包含 `manifest.json` 的目录）。
4. 打开任意超星学习通课程章节学习页（URL 含 `/mycourse/studentstudy`），页面右下角即会自动显示可拖动控制面板，也可点击浏览器右上角扩展图标打开工具栏控制弹窗。
