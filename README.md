# 超星学习通自动倍速与任务点助手 (Chaoxing Auto Speed & Task Helper)

一款面向 **Chrome / Edge (Manifest V3)** 的超星学习通（泛雅 MOOC）章节学习辅助浏览器扩展，支持 **[1, 16] 自由倍速调节**、基于服务端真实心跳阈值逆向的 **MAX 动态极速档位**、**视频 / PPT / PDF 全任务点自动完成**、**自动切换下一节** 以及 **可拖动悬浮窗 + 工具栏弹窗双控**。

---

## 功能特性

- **[1, 16] 无级调速与快捷预设**：
  - 支持滑块微调（步长 `0.05x`）、数字输入框精确输入，以及 `1x` / `2x` / `3x` / `4x` / `8x` / `16x` 快捷按钮。
  - 自动解除超星 `videojs-ext` 倍速限制、进度条拖动限制与窗口失焦暂停检测。
- **MAX 动态极速档位（逆向实测最优阈值）**：
  - **原理解析**：超星视频播放器每 `60s` 真实时间发送一次日志心跳（`reportTimeInterval = 60`）。虽然前端参数 `rt = 0.9` 要求时间轴进度覆盖 90%，但在课程开启 `ds_1`（允许倍速）时，服务端允许单次 60 秒心跳推进最多 4 倍视频时间轴进度（240 秒）。因此服务端真实观看时长（`playTime`）的实际通过阈值为：
    $$\text{真实时长阈值} = \frac{rt}{4} = \frac{0.9}{4} = 22.5\%$$
  - **动态控速策略**：`MAX` 档位采用 **25% 真实观看时长安全目标**（预留 2.5% 缓冲），实时根据服务端 `att.playTime` 与本地心跳累计时长动态计算倍速：
    $$R = \operatorname{clamp}\left(\frac{D - \text{当前进度}}{0.25 \cdot D - \text{真实已看时长}},\, 1,\, 16\right)$$
  - 从 `00:00` 起自动以 `4x` 稳步累计有效心跳时长；一旦真实观看时长达到 `25%`（或存在历史重看时长余量），立即自动切换 **16x 满速冲刺** 直至完成视频任务点。
- **开关键位与快捷键 (`Alt + S`)**：
  - 点击悬浮窗右上角开关按钮、扩展工具栏弹窗开关，或按下快捷键 `Alt + S` 即可随时开启/关闭。
  - 关闭时自动将当前视频恢复为 `1x` 正常倍速并停止自动跳转。
- **全类型任务点识别与自动下一节**：
  - 自动识别并完成视频、PPT、PDF 文档任务点（等待服务端返回 `isPassed: true` / `ans-job-finished` 后再跳转，杜绝漏刷与橙色未完成标记）。
  - 当前章节所有卡片完成后自动进入下一章节，到达末尾时自动回扫未完成章节。
- **可拖动悬浮窗与状态持久化**：
  - 按住悬浮窗标题栏即可自由拖动，窗口坐标、倍速档位、开关状态自动保存在 `localStorage`。

## 安装方法（Chrome / Edge）

1. 下载本仓库源码（或解压 `chaoxing-extension.zip`）。
2. 打开浏览器扩展管理页并开启**开发者模式**：
   - **Microsoft Edge**：地址栏输入 `edge://extensions/` 并回车，开启左侧或右上角的 **“开发人员模式” (Developer mode)**。
   - **Google Chrome**：地址栏输入 `chrome://extensions/` 并回车，开启右上角的 **“开发者模式” (Developer mode)**。
3. 点击 **“加载解压缩的扩展” (Load unpacked)**，选择本项目的文件夹（包含 `manifest.json` 的目录）。
4. 打开任意超星学习通课程章节学习页（URL 含 `/mycourse/studentstudy`），页面右下角即会自动显示可拖动控制面板，也可点击浏览器右上角扩展图标打开工具栏控制弹窗。
